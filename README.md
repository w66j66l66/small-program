# small-program
爬虫简介：
以下两个文件实现的功能相同，只是保存的文件形式不同。
文件1：cctv.py----保存为word文档。
文件2：每日新闻新版源代码.py----保存为PDF格式。
这个小程序爬取央视新闻公开数据（包括新闻正题、标题和出处等）
程序运行可能要几分钟，结束后将爬取的内容会自动保存为PDF格式。保存在“每日新闻新版源代码.py”文件的同级目录里。
Crawler Introduction: 
These two files have the same functionality, only the format of the saved file is different.
File 1: cctv.py — saves as a Word document
File 2: Daily News New Version Source Code.py — saves as a PDF
This little program crawls publicly available CCTV news data (including the main content, title, and source, etc.).
It might take a few minutes to run, and when it finishes, the crawled content will be automatically saved as a PDF in the same directory as the "Daily News New Version Source Code.py" file.
